1. When Can a Block Diagram Be Considered for Copyright? 
A block diagram can potentially be protected as an original artistic work when the diagram itself contains original 
visual expression—such as the student's original arrangement, graphical presentation, symbols, typography, layout and 
annotations. Copyright protection concerns the expression in the diagram; it does not give exclusive rights over the 
underlying idea, system concept, algorithm, process or functionality merely because these are represented in the 
diagram. 
 
Use a diagram created by the student/team, not a copied diagram from a paper, website, textbook, vendor manual 
or GitHub repository. 
 
If standard symbols are used, the student's originality should lie in the overall original visual arrangement and 
presentation, not a claim to ownership of common symbols. 
 
If the diagram is simply a screenshot/export from third-party software/template, verify the software/template 
licence and do not claim third-party elements as original. 
 
If the diagram is used or capable of being used in relation to goods/services, the Copyright Rules contain additional 
requirements for artistic works; see the official guidance before filing.

A team may have multiple copyrightable works, but the Copyright Rules state that each application is in respect of one 
work only. Therefore, do not assume that one application automatically covers the source code, report and block 
diagram as separate works. 
9. Special Check for Artistic Works Used With Goods/Services 
The Copyright Rules contain an additional requirement where an artistic work is used or is capable of being used in 
relation to goods or services. In such cases, the application includes a statement to that effect and the prescribed Trade 
Marks Registrar certificate requirement. This is particularly relevant to logos/brand artwork and should not be ignored 
merely because the artwork is also a project diagram. 
IMPORTANT: For a technical block diagram used only as project documentation, determine the facts before treating 
it as artwork used in relation to goods/services. If the same artwork is a commercial logo/brand asset, separately assess 
trademark implications.

☐ An editable master/source file is retained. 
☐ The diagram contains no confidential credentials. 
☐ If the diagram is a logo/brand asset, trademark requirements have been considered. 
☐ If the project also contains patentable technical subject matter, patent filing timing has been considered before public 
disclosure.
